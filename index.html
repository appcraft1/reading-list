Database Google Sheets (Cloud Sync)

Hubungkan aplikasi ke Google Spreadsheet bersama atau pribadi. Semua koleksi dan akun akan tersinkronisasi di cloud secara gratis tanpa biaya server.

Dapatkan URL dari deploy Web App spreadsheet Google Anda.
Cara Menghubungkan Google Sheet (3 Langkah):
  1. Buat spreadsheet baru di sheets.new.
  2. Klik menu Extensions (Ekstensi) > Apps Script.
  3. Hapus kode bawaan, lalu tempel kode dari tombol di bawah.
  4. Klik Deploy > New deployment > pilih Web app > ubah Who has access ke Anyone.
  5. Salin URL Web App yang muncul, lalu tempel ke kolom di atas dan klik Simpan & Hubungkan!
